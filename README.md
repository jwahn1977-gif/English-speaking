# 말해요 영어 (English Speaking)

가족이 함께 쓰는 AI 영어 말하기 앱 (안드로이드)

- 🌱 **누구나 첫날부터**: 처음 켤 때 누가 쓰는지 고르면 수준에 맞게 시작해요. 알파벳 소리, 기초 단어, 생활 표현 50문장은 AI 없이도 돼요. 큰 글씨 모드도 있어요.
- ▶ **오늘의 공부 10분**: 복습 → 새 단어 → 패턴 → 말하기를 버튼 하나로
- 🗣️ **AI 튜터**: 롤플레이, 일상, 비즈니스, OPIc, 고급, 어린이 상황별 대화. 채팅 모드와 음성 모드를 지원하고, 틀린 표현을 고쳐 주며 대화가 끝나면 리포트를 보여줍니다.
- 📚 **단어장**: 카드 학습, 퀴즈, 발음 채점, 간격 반복 복습, AI로 주제별 단어장 생성
- 🧩 **패턴**: 대화·뉴스에서 나온 좋은 문장을 `I'm looking for ~` 같은 패턴으로 저장하고 말하기 복습
- 🎧 **뉴스 듣기**: 영어 뉴스를 문장별로 듣기(원문 또는 쉬운 영어). 속도·반복·자막 숨기기, 쉐도잉, 핵심 단어와 질문 제공

## 설치

1. GitHub의 **Actions** 탭에서 가장 최근 성공한 실행을 엽니다. 아래 **english-speaking-apk**를 내려받아 압축을 풀면 APK가 나옵니다.
   `v0.1.0`처럼 태그를 붙이면 **Releases**에도 APK가 첨부됩니다.
2. 폰에서 APK를 엽니다. "출처를 알 수 없는 앱 설치"를 허용하고 설치합니다.
3. 업데이트할 때 기존 데이터를 유지하려면 모든 빌드를 같은 키로 서명해야 합니다. 아래 "서명 키" 설정을 참고하세요.

## AI 연결 (처음 한 번)

**구독 계정으로 로그인 (Claude Pro · ChatGPT Plus · Gemini) — 추가 요금 없음**
1. 설정 → AI 연결 → **Claude 로그인 / ChatGPT 로그인 / Gemini 로그인** 중 하나를 눌러 공식 앱이나 사이트에 로그인해 둡니다.
2. AI 튜터에서 상황을 고르면 **"Claude에서 대화 시작하기"**가 나옵니다. 누르면 앱이 만든 수업 지시문이 공식 앱으로 넘어갑니다. Claude·ChatGPT는 입력칸에 미리 채워지고, Gemini는 붙여넣기만 하면 됩니다.
3. 대화가 끝나면 END를 보내고, 마지막 답을 복사한 뒤 **"복사한 결과 가져오기"**를 누릅니다. 패턴과 단어가 복습에 들어갑니다.
4. AI 단어장·패턴 만들기도 같은 방식으로 됩니다.

> 각 회사가 구독 계정을 다른 앱의 AI 엔진으로 쓰는 것을 허용하지 않기 때문에, 대화는 공식 앱 안에서 합니다. 앱 안에서 바로 교정과 자동 저장까지 하려면 아래 API 연결을 쓰세요.


**API 연결: 웹 로그인 (앱 안에서 바로 대화·교정·자동 저장)**
앱 처음 화면이나 **설정 → AI 연결**에서 **웹 로그인으로 연결하기**를 누릅니다. 브라우저에서 OpenRouter에 로그인(구글 계정 가능)하면 앱으로 돌아와 자동 연결됩니다.
- 한 계정으로 Claude·ChatGPT·Gemini 모델을 모두 고를 수 있어요.
- 쓴 만큼 충전 금액에서 빠지며, 이름에 `:free`가 붙은 무료 모델도 있어요.

**회사별로 직접 연결 (고급)**
- 설정 → AI 연결 → "회사별 키로 직접 연결"을 엽니다.
- "웹에서 로그인하고 키 받기"를 누르면 해당 회사 사이트가 열립니다. 거기서 만든 키를 복사해 돌아오면 자동으로 채워집니다.
- Claude Pro, ChatGPT Plus 같은 **구독 계정은 다른 앱에 연결할 수 없어** API 키가 필요합니다.

**알아두기**
- 키는 그 폰 안에만 암호화되어 저장되고, 백업 파일에도 들어가지 않습니다.
- AI 기능을 쓰면 입력한 내용이 연결한 AI 회사로 전송됩니다.
- 왕초보 과정, 단어장, 복습, 뉴스 원문 듣기는 AI 없이도 됩니다.
- 설정 → AI 사용량에서 오늘·이번 달 사용량을 보고, 프로필별 하루 한도를 정할 수 있습니다.

## 가족과 공유

- **한 폰을 같이 쓸 때**: 설정 → 가족 프로필에서 사람을 추가합니다. 사람마다 학습 기록, 레벨, 설정이 따로 저장되고, AI 연결은 함께 씁니다.
- **각자 폰을 쓸 때**: 아래 백업 파일로 단어장과 패턴을 나눕니다.

**설정 → 백업 · 가족과 공유 → 내보내기**로 파일을 만들어 가족에게 보냅니다. 받은 사람은 **가져오기**를 누르면 단어장, 패턴, 내가 만든 시나리오, 뉴스 피드가 합쳐집니다.

### 서명 키 (업데이트 설치용)

서명 키는 저장소에 올리지 않습니다. GitHub 저장소의 **Settings → Secrets and variables → Actions**에 아래 두 값을 등록하면, Actions가 만드는 APK가 항상 같은 키로 서명됩니다.

| 이름 | 값 |
|---|---|
| `KEYSTORE_BASE64` | `base64 -w0 family.jks` 결과 |
| `KEYSTORE_PASSWORD` | 키스토어 비밀번호 |

키 만들기: `keytool -genkeypair -keystore family.jks -alias family -keyalg RSA -keysize 2048 -validity 36500`

로컬에서는 `keystore/family.jks`가 있으면 그 키로 서명합니다. 비밀번호는 환경변수 `KEYSTORE_PASSWORD`로 지정합니다.
Secrets가 없으면 debug 키로 서명합니다. 이 경우 설치는 되지만 빌드마다 서명이 달라져, 업데이트하려면 지우고 다시 설치해야 합니다(설치 전에 백업하세요).
