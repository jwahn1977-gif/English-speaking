# 말해요 영어 v0.2 검토: 편의성 · 전문성 · 접근성

> 목표: **영어를 전혀 모르는 사람, 어린이, 어르신, 화면이 잘 안 보이는 사람**까지 가족 누구나 쉬운 영어부터 시작할 수 있게.
> 방법: 현재 코드 점검과 공개 자료(학습 연구, 안드로이드 접근성 가이드, 학습 앱 온보딩 사례) 조사. 출처는 맨 아래에 있습니다.

## 3. 진단과 처방

### 3-1. 편의성

| 발견 | 근거(코드) | 처방 |
|---|---|---|
| 첫 실행 안내 없음 | `ui/home/HomeScreen.kt` — 바로 홈, AI 연결 카드만 표시 | **3단계 온보딩**: ① 누가 쓰나요?(어린이 / 처음 / 조금 해 봤어요 / 자신 있어요) ② 목표(여행·일상·업무·시험·아이 공부) ③ 글자 크기·말하기 속도 미리 보기. 선택에 따라 레벨, 읽기 속도, 첫 코스를 자동 설정. AI 연결은 "나중에"로 미룰 수 있게 |
| 수준 측정이 없음 | `TutorLevel.AUTO`는 대화에서 쓴 단어 수로만 판단 | 조사 결과 자기 선택은 빠르지만 부정확하고, 시험은 초보에게 부담이 된다. **자기 선택 + 선택형 1분 체크**(듣고 그림 고르기 5문항)를 함께 제공하고 언제든 바꾸기 |
| 메뉴를 스스로 골라야 함 | 홈의 "바로 시작" 4개 | **"오늘의 학습 10분" 한 버튼**: 복습 → 새 단어 5개 → 패턴 1개 → 튜터 3턴(또는 뉴스 3문장)을 자동으로 이어서 |
| API 키 설정이 어려움 | 설정에 3사 카드 동시 표시 | "가장 쉬운 방법" 안내: Gemini(무료 사용량 있음)를 1순위로, 단계별 그림 안내, 붙여넣기 버튼, 키 자동 검사 |
| AI 사용량이 안 보임 | `LlmClient` 사용량 기록 없음 | 호출 횟수와 대략적인 토큰을 하루·월 단위로 표시하고, **하루 한도**(예: 어린이 프로필 30회) 설정 |
| 실수 되돌리기 없음 | `StudyScreens.kt:185` 알아요/몰라요 즉시 확정 | 직전 카드 "되돌리기" |

### 3-2. 전문성 (학습 설계)

| 원칙 (근거 강도) | 현재 | 처방 |
|---|---|---|
| **간격 반복**은 가장 많이 검증된 학습 효과 (강함) | 라이트너 5단계 ✅ | 유지. 단, 틀린 카드는 **같은 학습 안에서 3~5장 뒤 다시 출제**(`Learning.kt:56`, `StudyScreens.kt:185` 수정) |
| **이해 가능한 입력**이 먼저, 말하기(출력)는 굳히는 역할 (중간, 이론 기반) | 원문 뉴스와 튜터가 바로 노출됨 | 초보에게는 **듣기 → 따라 읽기 → 바꿔 말하기** 순서. 뉴스는 레벨이 낮으면 "쉬운 영어"를 기본 선택으로 |
| **쉐도잉**은 초보에게 바로 쓰지 말고 이해한 문장으로 (약함, 실무 경험 위주) | 모든 레벨에서 쉐도잉 버튼 | 초보 모드에서는 먼저 한국어 뜻을 확인한 뒤 따라 말하기. 0.7배를 기본값으로 |
| **고빈도 어휘부터** (어린이는 Cambridge Pre A1 Starters 단어 목록이 6~12세용) | 기본 60단어가 A2~B1 | **0단계 "왕초보 코스"**: 알파벳 소리·파닉스 26 → 기초 300단어(숫자·색·가족·음식·몸·동사 50) → 생활 표현 50문장(인사, 감사, 부탁). **AI 없이 동작**하도록 앱에 내장 |
| **선택지 → 부분 완성 → 자유 발화**로 단계적 도움 (교수법 일반 원칙) | 튜터가 자유 발화만 요구 | 튜터 응답에 **추천 답변 2~3개**(쉬운 것 → 긴 것)를 추가. 초보는 눌러서 듣고 따라 말하기, 중급 이상은 숨김 |
| 레벨을 국제 기준과 연결 | 자체 레벨 6단계 | 각 레벨 옆에 CEFR(Pre-A1~C1)을 함께 표시하고, "할 수 있는 일" 문장으로 설명(예: "자기 이름과 나이를 말할 수 있어요") |
| 점수 이름은 측정하는 것과 같아야 함 | "발음 점수"는 단어 일치율 | 이름을 **"알아듣기 점수"**로 바꾸고 "기기가 알아들은 단어 비율"이라고 설명 |

### 3-3. 접근성 (Android 접근성 가이드 기준)

| 기준 | 발견 | 처방 |
|---|---|---|
| 글자 크기 확대 시 잘림 없음 | 챕터 카드 `VocabScreens.kt:103` 고정 88×112dp, 원형 게이지 숫자 | 고정 높이를 최소 높이(`heightIn`)로 바꾸고, 큰 글씨에서는 게이지를 세로 배치 |
| **앱 자체 큰 글씨 모드** | 없음 (시스템 설정만 따름) | 설정에 "글자 크기 보통 / 크게 / 아주 크게" 추가, 학습 카드는 더 크게 |
| 색만으로 정보 전달 금지 | 말하기 결과가 초록/빨강 글자만으로 구분 `StudyScreens.kt:72` | 맞은 단어 ✓, 틀린 단어 밑줄과 ✗를 함께 표시. 퀴즈 정답·오답도 아이콘 병행 |
| 터치 영역 48dp 이상 | 머티리얼 버튼은 충족, 뉴스 문장의 마이크 `size(36.dp)` 미달 | 48dp로 상향 |
| 음성 안내(TalkBack) 라벨 | 클릭 가능한 카드 23곳에 `onClickLabel` 없음, 아이콘 14곳이 설명 없음 | 카드마다 "열기: 카페에서 주문하기" 같은 클릭 라벨 추가. 꾸미기 아이콘은 생략하고, 의미 있는 아이콘에는 설명 추가 |
| 소리를 못 들어도 학습 가능 | 듣기 퀴즈가 소리에만 의존 | "소리 없이" 옵션: 듣기 문제 대신 글자 문제 |
| 말하기가 어려운 사람 | 대부분 입력 대체 가능 ✅ | 유지. 말하기 채점 카드에서 "건너뛰기" 명시 |
| 움직임 줄이기 | 자동 스크롤 애니메이션 | 시스템의 "애니메이션 제거" 설정을 따르기 |

### 3-4. 안전 · 가족

- 대화 내용은 사용자가 고른 AI 회사로 전송됩니다. 첫 사용 시 한 줄 안내가 필요하고, 어린이 프로필에서는 이름 같은 개인정보를 말하지 않도록 튜터 프롬프트로 유도해야 합니다.
- 어린이 시나리오의 AI 응답은 "아이용, 짧고 친절하게" 지시가 이미 있습니다. 여기에 **주제 이탈 방지**("수업 주제와 관계없는 이야기는 부드럽게 돌아오기")를 추가합니다.

## 4. 실행 계획

### P0 — "누구나 첫날부터" (v0.3, 약 1~1.5주)
1. 첫 실행 온보딩(대상, 목표, 글자 크기, 속도) → 레벨, 첫 코스, 기본값 자동 설정
2. **왕초보 코스(AI 없이 동작)**: 소리·파닉스, 기초 300단어, 생활 표현 50문장, 어린이 그림(이모지) 카드
3. 튜터 **추천 답변 칩** + 초보 모드에서는 힌트를 상시 노출
4. 같은 학습 안에서 오답 재출제, 직전 카드 되돌리기
5. 접근성 기본 정비: 큰 글씨 모드, 고정 크기 제거, 색과 기호 병행, 클릭 라벨, 48dp 터치 영역

### P1 — "꾸준히, 알맞게" (v0.4)
6. "오늘의 학습 10분" 자동 코스
7. 레벨에 CEFR과 "할 수 있는 일" 표시, 1분 듣기 체크
8. 점수 이름 정정(알아듣기 점수), 소리 없이 학습 옵션
9. AI 사용량 표시와 하루 한도, 쉬운 API 키 설정 안내
10. 레벨이 낮으면 뉴스를 쉬운 영어로 기본 설정, 0.7배 기본

### P2 — "가족 맞춤" (v0.5 이후)
11. 한 폰에서 가족 프로필 전환(아이별 한도, 진도 분리)
12. 고품질 음성, AI 답변 실시간 표시(스트리밍)
13. TalkBack·큰 글씨 실기기 점검표로 정기 확인
